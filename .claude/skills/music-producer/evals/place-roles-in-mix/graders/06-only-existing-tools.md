Every setting the sheet asks for exists in Faulk today (track pan, Reverb, Echo, Filter, Bloom, Drums, Oscillator, Stack); the sheet does not ask for an equaliser band, a send or return track, a mono switch, a width or phase utility or a spectrum reading, and where it would need one it names it as missing.
