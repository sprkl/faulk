# Faulk documentation

Documentation is in French; frontmatter, indexes and logs are in English. The code is the source of truth: a document with `status: draft` has not been checked against the code.

* [Architecture](architecture/) - Technical architecture: one Rust engine, two targets (WASM in the browser, native helper), web UI.
* [Constraints](constraints/) - Cross-cutting requirements: real-time audio, latency, licences, legal stance on recreating plugins.
* [Design](design/) - Design system brief and visual references.
* [Specs](specs/) - Functional and technical specifications.
* [Spikes](spikes/) - Technical de-risking studies run before implementation.
* [Agent configuration](agents/) - Configuration read by the engineering skills: issue tracker, triage labels, domain docs, reviewer, verification.
