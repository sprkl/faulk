* **Feature** (#555): a placement repeats up to a bar. New command `arrangement.repeat { placement, until }` (edit, undo through `arrangement.restore`, one history entry): linked copies of the placement (new placements of the same clip, same length and offset) laid end to end from the placement's end up to the tick `until`; the one that would pass `until` is shortened to stop there; the copies win on overlap. Refused: an unknown or audio placement, `until` not after the placement's end or past 2^40, and a number of copies that passes the per-track limit (checked before any copy is made). `PROTOCOL_VERSION` 21. Web: "Repeat until…" (button, clip context menu, Ctrl+Shift+R, taken wherever the focus is so the browser does not reload) asks for a bar and repeats through its end; "Duplicate" (Ctrl+D) and "Duplicate linked" (Ctrl+Shift+D) are now in the shortcut list. The Clips tab already shows a linked clip as one row with its placement count. Tests: command (semantics, one undo, refusals, contract examples), engine messages, the helpers, and an end-to-end spec (8 bars repeated to bar 64: 8 placements of one clip, "8 in the arrangement", keyboard, button, menu).
