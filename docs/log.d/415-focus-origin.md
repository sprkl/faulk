* **Fix** (#415): after closing a control's context menu by clicking an item (`Slider.closeMenu()` → `root.focus()` with pointer as last input), the focus origin stayed stale — a subsequent `focus()` call on the already-focused element fired no `focusin`, so `pointerFocused` was never cleared. A key press on the same control then failed to reassert keyboard origin, and Space incorrectly toggled the transport. Fix: a non-Space, non-modifier `keydown` on the already-focused element now clears `pointerFocused`, making `spaceTogglesTransport` deterministic. Regression test added to `continuous.spec.ts`; `keyboard.test.ts` covers the new rule.
