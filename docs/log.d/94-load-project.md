* **Update** (#94): opening a project into the engine (SV-4). `project.open` (`crates/commands/src/project.rs`) replaces the project, its history and its session from a folder the host stages in the command context, refuses a bad folder with a typed `FolderError` and leaves the current project intact; `Synced::run` answers it with a `Reset` in the next epoch and the snapshot of the new project, so the page and the render harness start the engine over. The provisional `load_files` of `commands::host` and `pw_load` of `project-wasm` are replaced by the folder format of SV-1 (`pw_stage`: a bounded folder frame, blobs listed by size). Described in `docs/architecture/02-modele-projet.md` § 2.7 and `docs/agents/verification.md`.
