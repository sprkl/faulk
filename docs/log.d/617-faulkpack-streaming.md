* **Update** (#617): the `.faulkpack` export is written as a stream, file by file (`project::file::PackWriter`, the `pw_pack_begin/next/feed/cancel` session of `project-wasm`): the blobs are read from the store in 1 MiB pieces and the zip goes to a file chosen by the user or to a download, with progress and cancel (new command `project.cancel_export_pack`, protocol 33), so memory no longer depends on the project's size and the 180 MiB export limit is gone; the page's import (192 MiB) is unchanged.
