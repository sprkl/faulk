* **Update**: in the Clips panel, "Place at the playhead" (button and Enter) now places the same clip, linked; a "Place a copy" button (or Alt on Place) places an independent copy of a clip already used. The placement it makes is selected in the arrangement and takes the keyboard focus (a one-shot `ui.showPlaced` request), so the next key (Ctrl+Shift+R, Ctrl+D, Delete) applies to it. Two clips of one name in the pool are shown with a number. No command changed: the same `arrangement.place`, `arrangement.place_from_slot` and `arrangement.duplicate` commands are chosen the other way round. "Put in the grid" and the drag keep their rule (a copy by default, Alt for the clip itself) (#624).
