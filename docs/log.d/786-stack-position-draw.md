* **Update** (#786): Stack's chance draws from the note's position in the song, not from a count of notes: a hash of the seed, the position in ticks (the block's `position_ticks` plus the offset at the tempo) and the key, one number per voice, through `engine::devices::draw`, the module shared with Scatter (#691), same rule. An export equals a play from any start, a seek or a loop draws the same chords, and a live note shifts no other draw (while stopped, a live note counts from the last reset). A chance of 0 % or 100 % keeps the chord of existing projects; between the two, the chords drawn differ from before. Two notes of the same key at the same tick draw alike (the rule of Scatter). No protocol change.
* **Update** (#788): the table of held notes, the scale-degree moves and the parameter descriptor constructors that Stack and Scatter both had live in `engine::devices::{held, scale, params}`; behaviour unchanged.
