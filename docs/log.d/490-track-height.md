* **Update** (#490): the height of a track's row is the project's. `Track.height` (28 to 176 px, optional, not written when unset) is set by `track.set_height` (undoable, `null` is the default of the density) and written in `track.json`; folder format 3 (a format 2 folder migrates by its number alone; a format 2 build calls a format 3 folder "newer" instead of corrupt); protocol 20. The page keeps no lane heights of its own any more (the ones an earlier build kept in the layout are ignored). A density setting, comfortable or compact, sits in the project menu, is kept in the browser and sets `data-density`.
